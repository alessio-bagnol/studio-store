# Studio Store 🛍️

Boutique en ligne moderne pour puffs, accessoires et équipements audio (Studio Store).

## Stack Technique
- **Frontend** : React SPA + Tailwind CSS + Lucide Icons + Framer Motion
- **Déploiement** : Vercel / GitHub Pages
- **Serverless API** : Vercel Functions (`/api/products`, `/api/formules`, `/api/promocodes`, `/api/orders`)
- **Paiement & Livraison** : Stripe Elements, API Adresse Gouv

## Déploiement Vercel
1. Rendez-vous sur [Vercel Dashboard](https://vercel.com/new).
2. Importez le dépôt `alessio-bagnol/studio-store`.
3. Cliquez sur **Deploy**.
